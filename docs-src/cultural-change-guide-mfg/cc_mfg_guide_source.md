## Part 0 — Purpose and How to Use This Guide

### What this guide is

This guide is a single, focused companion to journi's cultural / values transformation archetype — the one journi's own Cross-Type Comparison Matrix rates as its longest-running, least externally-forced, and most reversibility-fragile transformation type, and the only one of journi's ten archetypes whose end-to-end process chain skips Macro Process 5 (Training & Capability Enablement) entirely. Rather than tour all of journi's modules and archetypes at once, it follows one real, complex Change Management Project — **One Bouregreg: Post-Acquisition Culture Integration** — from a genuinely new tenant setup through institutionalization, week by week, in the same operational depth a Change Manager would actually need to run it.

It is organized in five parts:

- **Part 0 — Purpose and How to Use This Guide.** This part.
- **Part 1 — Executive Summary.** Why this specific case is journi's most complex cultural transformation to run, and what this guide's own numbers say about it.
- **Part 2 — The Four Frameworks and What Is Specific to Cultural / Values Change.** journi's four change frameworks, re-weighted for an archetype where Bridges and Kübler-Ross dominate over ADKAR, and where a merger of two workforces raises the emotional stakes further still.
- **Part 3 — Tenant and Admin Setup.** Building the journi tenant this program runs in, from the License record through the live Change Management Project, using journi's own manufacturing-sector scenario organization, Bouregreg Group, and the new Organization this acquisition adds to it.
- **Part 4 — Week-by-Week Cultural / Values Timeline: Normal Flow and Exceptions.** The full 78-week program run forward week by week, Project Manager and Change Manager tracks side by side, with the exact journi entries to type in; then, in the same level of detail, six realistic exception patterns; then two Master WBS & Gantt views of the whole program's task and step structure.

### How to use it

Read Part 3 once, at setup time, or skip it if the tenant already exists — this guide's Bouregreg Group tenant is the same one journi's Master User Guide builds for its own ERP program, so a reader who has already worked through that guide's Part 1 can jump straight to this guide's Part 3, Section 3.3 onward, where the Tangier acquisition and this specific Change Management Project begin. From there, Part 4 is written as the day-to-day operating manual for the Change Manager and Program Manager running this program together.

### A note on fidelity

Every journi module, field, and role named in this guide is verified against journi's actual source and the same tenant model journi's Master User Guide uses, not assumed from a spec. Where a real constraint applies — journi's Organization sector is one of exactly three values (Manufacturing, Logistics, Health); a Change Management Project may link to zero, one, or more Main Projects; journi's RBAC model has exactly nine roles — this guide states that constraint rather than working around it.

### A note on the RACSI codes used throughout

Part 4's RACSI tables use journi's separate 7-code RACSI role taxonomy (ES/CM/PM/FPO/ITL/SUP/EU), which the End-to-End Process Registry (M18) and Charter Registry (M19) both use — this is deliberately distinct from the 9-role platform RBAC enum (Super Admin, Group Admin, Org Admin, Change Manager, People Manager, Sponsor, Executive, Employee, Practitioner/Contributor) that Part 3 uses to create real journi user accounts. **ES** = Executive Sponsor, **CM** = Change Manager, **PM** = Program/Project Manager, **FPO** = Functional Process Owner, **ITL** = IT/Technical Lead, **SUP** = Supervisor, **EU** = End User. Part 3 states, for every named team member, both their journi RBAC role and the RACSI code they hold in Part 4's tables, since one person typically carries one of each.

- **A Program/Project Manager focused on the PM ↔ CM boundary:** Part 4's PM Track column throughout, and the Master WBS & Gantt (Section 4.6).

## Part 1 — Executive Summary

### 1.1 Why This Is journi's Most Complex Cultural Change

journi's Cross-Type Comparison Matrix (SRS 10.6.14) already rates Cultural / Values Transformation as its longest, least externally-forced, and most reversibility-fragile archetype. **One Bouregreg** adds a complication that a single-organization values program never has to face: it is not building a culture from a blank slate — it is merging two workforces who each already have one, under time pressure, while the acquiring company's own 3,400-person ERP program (journi's own throughline scenario) is still mid-flight in the background.

Three facts drive the "most complex" call for this specific case:

- **There are two starting cultures, not one.** Bouregreg Manufacturing Maroc's plant-floor culture (Casablanca, Kenitra, Settat) and the newly acquired Tangier Distribution operation's own way of working did not evolve together. A diagnosis here has to characterize *two* baselines and the gap between them, not one baseline against a target.
- **The power imbalance is built into the situation, not the program design.** Tangier's 260 staff know, structurally, which company acquired which. Every value this program installs has to survive being read, by the acquired team, as either genuine or as the acquirer's culture with new branding — the single hardest trust problem in this guide's whole scenario library.
- **The Sponsor starts behind, by design.** The newly appointed integration Sponsor, Karim Fassi, has logged no visible action in journi at program start — journi's own Sponsor Coverage Gap alert (ALT-003) is built to fire in this program's first weeks, before his first town hall is logged. A cultural program's dominant frameworks (Bridges, Kübler-Ross) are exactly the ones a visibly absent Sponsor damages fastest.

### 1.2 The Case, in Brief

Six months into Bouregreg Group's ERP Platform Unification program, Bouregreg Group acquires a smaller regional competitor's Tangier distribution operation. **One Bouregreg** is the 18-month, 78-week culture integration that follows — installing four shared values (**Equal Standing, One Way of Working, Shared Ownership, Speak Plainly Across Sites**) across the acquired Tangier team (260 staff) and their Bouregreg counterparts (roughly 140 staff in Casablanca-based supply chain, sales, and customer-facing roles who now work directly with Tangier), so that the acquisition's stated synergies — one combined distribution network, one set of customer commitments — actually materialize rather than stall on two workforces that never became one company.

### 1.3 What This Guide Proves, Concretely

Every claim above is traceable to a real journi record this guide builds: a Sponsor Coverage Gap that actually fires (Section 4.1, Phase 2), a Divergence Pattern between stated and demonstrated values (Section 4.4's exceptions), a Composite Readiness Index and Benchmarking trend that dips before it recovers, and a Refreeze justification signed only once the evidence — not the acquisition's own press-release timeline — supports it.


## Part 2 — The Four Frameworks and What Is Specific to Cultural / Values Change

### 2.1 journi's Four Frameworks, in Their Real Stage Vocabulary

journi tracks four change frameworks, each at a different altitude, logged on two modules:

| Framework | Altitude | Stages (in journi's own UI, in order) | Logged on |
|---|---|---|---|
| Lewin | Organizational — one reading per project | Unfreeze → Change → Refreeze | M3 (Initiative Registry) |
| Prosci ADKAR | Individual / cohort — five independently-scored blocks | Awareness → Desire → Knowledge → Ability → Reinforcement | M5 (ADKAR Engine) |
| Bridges' Transition Model | Individual / cohort — emotional position | Ending → Neutral Zone → New Beginning | M6 (Emotional & Transition Layer) |
| Kübler-Ross Change Curve | Individual / cohort — sentiment | Denial → Resistance/Anger → Exploration → Commitment | M6 (Emotional & Transition Layer) |

None of the four is auto-computed by journi. All four remain a Change Manager's evidence-based judgment call, logged with a written justification under Bouregreg Group's Governance Setting. The two things journi does compute automatically are the Composite Readiness Index (M14, Analytics — blending ADKAR 50%, Kübler-Ross sentiment 25%, and training completion 25%) and the Divergence Pattern Detector (ALT-001, firing when Knowledge ≥ 4 and Ability ≥ 4 while Bridges still reads exactly "Ending").

### 2.2 Why the Weighting Is Different for a Cultural / Values Change

An ERP program like Bouregreg's own is read almost entirely through Lewin and ADKAR: a system either works or it doesn't, and Knowledge and Ability are the blocks that matter most. **One Bouregreg** inverts that weighting.

- **Bridges dominates.** For Tangier's staff, this program is not a new tool to learn — it is the end of being a separate company. Ending is not metaphorical here: real reporting lines, a real company name, and real local autonomy are actually ending. Bridges' three stages track that loss directly in a way ADKAR's competence-oriented blocks were never built to.
- **Kübler-Ross dominates alongside it.** The emotional register of "our company was bought" is closer to grief than to a training gap. Denial, Resistance/Anger, Exploration, and Commitment are the honest emotional sequence this program expects to see — not a shortcut to skip past.
- **ADKAR still matters, but differently.** Awareness and Desire carry the real weight here (does Tangier's team understand what "One Bouregreg" actually changes for them day to day, and do they want it), while Knowledge and Ability — usually ERP's hardest blocks — are comparatively light, since this program is not teaching a new system.
- **MP-05 (Training & Capability Enablement) is absent from the process chain entirely.** journi's E2E-CULT chain (MP-01→02→03→04→06→07→08→09→10) is the only one of its ten archetype chains without a training Macro Process. You cannot train a Tangier employee into believing "One Bouregreg" is genuine; every mechanism in Part 4 exists because that lever is unavailable.

### 2.3 The Composite Readiness Index, Read for This Case

M14's blended score (ADKAR 50% / Kübler-Ross 25% / training completion 25%) was designed with a system-rollout program in mind, where training completion is a meaningful third of readiness. For **One Bouregreg**, the training-completion term stays structurally near zero for the program's whole life — there is no curriculum to complete — so this guide reads the Composite Readiness Index for this case as effectively an ADKAR/Kübler-Ross blend, and states that reading plainly in Section 4.1 rather than let a flat training term quietly understate the score's real meaning.

### 2.4 Benchmarking, for an Acquisition-Driven Case

journi's Benchmarking view compares this program's trajectory against its archetype's expected reference band. Because this case combines the Cultural archetype's already-long horizon with a starting Sponsor Coverage Gap and a structural trust deficit (Section 1.1), this guide's own Benchmarking reading (Section 4.1) expects — and is built to show — a slower-than-typical opening quarter before the trajectory catches the Cultural reference band, rather than treat any early "Behind" reading as itself a crisis.
