2. Core Principle: One Interface, Multiple Implementations

Build a single application (web, desktop, mobile, CLI, or embedded) with
an abstract licensing interface (LicenceProvider). A configuration flag
(DEPLOYMENT_MODE) determines whether it validates against a cloud
database (SaaS) or a local signed file (OnPrem).

Benefits:

-   No if (onPrem) branches scattered across the codebase.

-   Single configuration knob controls everything.

-   Extensible — new strategies can be added without changing core
    logic.

-   Works for any platform: web, desktop, mobile, CLI, embedded.

5.2. OnPrem Implementation by Platform

The core licensing logic is identical across all platforms. Only the
file reading mechanism differs.

A) Web Applications (Browser)

  -----------------------------------------------------------------------
  Strategy         How the File is Read               Use Case
  ---------------- ---------------------------------- -------------------
  A1: User Upload  <input type="file"> → User selects Simplest, no
                   file → App reads it, stores in     backend needed
                   localStorage                       

  A2: Self-Hosted  Backend reads                      Recommended for
  Backend          /app/data/license.lic → Serves via full OnPrem data
                   /api/license → Frontend fetches it residency

  A3: Electron /   fs.readFileSync() (Node.js/Rust) → Desktop wrapper for

6. Hardware Binding (Extra Security for Non-Web)

Non-web applications can implement stronger hardware binding because
they have access to system-level identifiers.

  ----------------------------------------------------------------------------
  Platform        Hardware Identifiers            Implementation
  --------------- ------------------------------- ----------------------------
  Windows         CPU ID, MAC address, Disk       WMI or Win32 API
                  Serial, Motherboard ID          

  macOS           MAC address, Hardware UUID,     IOKit or sysctl
                  System Serial                   

  Linux           CPU ID, MAC address, DMI/SMBIOS /sys/class/dmi/id/,
                  data                            /sys/class/net/

  Mobile          Android ID, MAC address, Device Settings.Secure.ANDROID_ID
  (Android)       ID                              

  Mobile (iOS)    Device ID, MAC address          identifierForVendor
                  (deprecated)                    

  Embedded        Serial number, MAC address,     STM32 Unique ID, Raspberry
                  unique chip ID                  Pi Serial
  ----------------------------------------------------------------------------

+-----------------------------------------------------------------------+
| // Node.js (Electron, CLI)                                            |
|                                                                       |
| function generateHardwareId() {                                       |
|                                                                       |
| const os = require('os');                                             |
|                                                                       |
| const crypto = require('crypto');                                     |
|                                                                       |
| const mac = os.networkInterfaces()['eth0']?.[0]?.mac ||               |
|                                                                       |
| os.networkInterfaces()['en0']?.[0]?.mac || '';                        |
|                                                                       |
| const cpu = os.cpus()[0]?.model || '';                                |
|                                                                       |
| const hostname = os.hostname();                                       |
|                                                                       |
| const totalMem = os.totalmem();                                       |
|                                                                       |
| const fingerprint = `${mac}|${cpu}|${hostname}|${totalMem}`;          |
|                                                                       |
| return crypto.createHash('sha256').update(fingerprint).digest('hex'); |
|                                                                       |
| }                                                                     |
+=======================================================================+
+-----------------------------------------------------------------------+

+-----------------------------------------------------------------------+
| # Python (Desktop, CLI)                                               |
|                                                                       |
| import hashlib                                                        |
|                                                                       |
| import uuid                                                           |
|                                                                       |
| import platform                                                       |
|                                                                       |
| import subprocess                                                     |
|                                                                       |
| def generate_hardware_id():                                           |
|                                                                       |
| # CPU serial                                                          |
|                                                                       |
| cpu = subprocess.check_output(['wmic', 'cpu', 'get',                  |
| 'ProcessorId']).decode().strip()                                      |
|                                                                       |
| # MAC address                                                         |
|                                                                       |
| mac = ':'.join(('{:02x}'.format((uuid.getnode() >> ele) & 0xff)       |
|                                                                       |
| for ele in range(5, -1, -1)))                                         |
|                                                                       |
| # Disk serial                                                         |
|                                                                       |
| disk = subprocess.check_output(['wmic', 'diskdrive', 'get',           |
| 'SerialNumber']).decode().strip()                                     |
|                                                                       |
| fingerprint = f"{cpu}|{mac}|{disk}"                                   |
|                                                                       |
| return hashlib.sha256(fingerprint.encode()).hexdigest()               |

8. The Vendor Signing Tool (Cross-Platform)

|                                                                       |
| const crypto = require('crypto');                                     |
|                                                                       |
| const fs = require('fs');                                             |

|                                                                       |
