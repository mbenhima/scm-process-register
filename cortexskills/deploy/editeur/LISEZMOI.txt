Premiers pas (sur votre poste, dans ce dossier)
  1. ./gestion-licences/cslic importer poste-signature && rm -r poste-signature
  2. ./gestion-licences/cslic-sauvegarder ~/coffre
  3. Scénario a :  copier application/ sur le serveur Linux, puis ./installer.sh serveur competences.mondomaine.ma auto
  4. Scénario b :  sous Windows (Docker Desktop), dans le terminal Ubuntu : cd application && ./installer.sh local
                   ou en PowerShell, sans script : guide, chapitre 5.
  Premier démarrage : chargement des données de référence de toutes les verticales et des PME (5 à 15 minutes).
