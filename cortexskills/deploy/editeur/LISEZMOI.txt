CortexSkills @VERSION@ — Paquet éditeur Docker (Linux)
Procédure complète : « CortexSkills — Guide d'installation éditeur (Docker) ».

  application/        CortexSkills pour vos propres installations (tarifs visibles), image déjà construite :
                        ./installer.sh local                                    scénario a — localhost (http://localhost:4000)
                        ./installer.sh serveur <nom DNS> [auto|internal|files]  scénario b — cloud privé / sur site (HTTPS)
                        ./licences.sh …       organisations et licences installées
                        ./sauvegarder.sh      sauvegarde hors du conteneur (et vers une autre machine)
                        ./mettre-a-jour.sh    passage à une nouvelle version
  gestion-licences/   sur VOTRE poste uniquement (s'exécute dans l'image éditeur, aucun code sur le poste) :
                        cslic                 créer, lister, afficher, modifier, renouveler, révoquer, supprimer, vérifier
                        cslic-sauvegarder     sauvegarde chiffrée des clés et du registre
  poste-signature/    votre paire de clés de signature : à importer une fois (cslic importer), puis à supprimer

Premiers pas (sur votre poste, dans ce dossier)
  1. ./gestion-licences/cslic importer poste-signature && rm -r poste-signature
  2. ./gestion-licences/cslic-sauvegarder ~/coffre
  3. Scénario a :  cd application && ./installer.sh local
  4. Scénario b :  copier application/ sur le serveur, puis ./installer.sh serveur competences.mondomaine.ma auto
Le paquet client (CortexSkills-Client-Docker-@VERSION@.zip et son .sha256) s'envoie tel quel à chaque client.
