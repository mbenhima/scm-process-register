CortexSkills @VERSION@ — Paquet client Docker (Linux)
Procédure complète : « CortexSkills — Guide d'installation client (Docker) », livré avec ce paquet.

Contenu
  cortexskills-client-docker-image-@VERSION@.tar.gz   l'image d'exécution CortexSkills, déjà construite
  docker-compose.yml     l'application, son volume de données et le HTTPS (Caddy, profil « https »)
  Caddyfile              configuration HTTPS (TLS_MODE : auto, internal ou files)
  env.example            modèle du fichier de réglages .env
  SHA256SUMS.txt         empreintes des fichiers du paquet
  licence/               déposez ici le fichier de licence (.lic) reçu de l'éditeur
  certs/                 (TLS_MODE=files) votre certificat cert.pem et sa clé key.pem

Démarrage rapide
  1. sha256sum -c CortexSkills-Client-Docker-@VERSION@.zip.sha256
  2. unzip CortexSkills-Client-Docker-@VERSION@.zip && cd CortexSkills-Client-Docker-@VERSION@ && sha256sum -c SHA256SUMS.txt
  3. docker load -i cortexskills-client-docker-image-@VERSION@.tar.gz
  4. cp env.example .env && chmod 600 .env && nano .env
  5. docker compose up -d && docker compose logs -f cortexskills
  6. docker compose exec cortexskills cortexskills-admin org-create --name "Votre entreprise" --domain votre-entreprise.ma \
       --admin-email admin@votre-entreprise.ma --admin-name "Prénom Nom" --admin-password '<mot de passe fort>' --lang fr
  7. docker compose exec cortexskills cortexskills-admin licence-request --org votre-entreprise.ma   → à envoyer à l'éditeur
  8. Copiez le fichier .lic reçu dans licence/, puis :
     docker compose exec cortexskills cortexskills-admin licence-install --file /licence/<fichier>.lic
