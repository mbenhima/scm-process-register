CortexSkills @VERSION@ — Exécutable minifié, côté éditeur (Linux x64 et Windows x64)
Procédure complète : Guide_Installation_Runtime_Editor_Linux_Windows_CortexSkills_FR (Word / PDF, livré avec ce fichier).
Aucun code source lisible : serveur et gestionnaire de licences minifiés, interface compilée et minifiée.
Prérequis : Node.js 22 LTS (22.13 ou plus) — installeur officiel sous Windows, archive officielle ou NodeSource sous Linux.

Deux scénarios
  a) Cloud privé / sur site (serveur Linux) : ./cortexskills, sudo ./installer-service.sh, config/ (systemd, Nginx).
  b) Localhost sous Windows (poste de l'éditeur) : cortexskills.cmd start, puis http://localhost:4000.

Contenu
  cortexskills / cortexskills.cmd   l'application et sa console (start, admin, secrets, backup, restore, version)
  cslic / cslic.cmd                 gestionnaire de licences (CRUD) du poste de signature
  cslic-sauvegarder                 archive chiffrée du poste de signature (Linux)
  installer-service.sh              service Linux (systemd)
  env.example                       modèle du fichier de réglages .env
  config/                           cortexskills.service, nginx-cortexskills.conf
  licence/                          fichiers de licence (.lic) à installer
  app/                              l'application (exécutable)
  poste-signature/                  paire de clés de signature : à importer une fois (cslic importer), puis à supprimer
  SHA256SUMS.txt                    empreintes des fichiers

Scénario b, Windows (invite de commandes, dans le dossier décompressé)
  copy env.example .env      puis dans .env : PUBLIC_URL=http://localhost:4000, CORS_ORIGIN=http://localhost:4000,
                             les deux secrets (cortexskills secrets), ADMIN_EMAIL, ADMIN_PASSWORD
  cortexskills start         (premier démarrage : 5 à 15 minutes)
  cslic importer poste-signature
  cslic aide
