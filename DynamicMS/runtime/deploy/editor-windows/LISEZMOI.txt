DynamicMS 2026.10 — runtime éditeur en local sur Windows 10/11 (Docker Desktop)

Contenu
  docker-compose.yml       définition du service (accessible sur http://localhost:4000)
  .env.example             modèle des paramètres (copié en .env par Install-DynamicMS.ps1)
  Install-DynamicMS.ps1    installation : contrôle, empreinte, chargement de l'image, clé, démarrage
  Start-DynamicMS.ps1      démarrage
  Stop-DynamicMS.ps1       arrêt (données conservées)
  Backup-DynamicMS.ps1     sauvegarde complète des données
  Restore-DynamicMS.ps1    restauration d'une sauvegarde
  secrets\                 emplacement de la clé privée de signature des licences

L'image utilisée est celle du runtime éditeur Linux (Docker Desktop exécute des conteneurs Linux) :
Docker_Runtime_Editor_Linux_DynamicMS_2026.10_Image.tar.gz

Installation : voir Guide_Installation_Docker_Runtime_Editor_Linux_Windows_DynamicMS_FR, chapitre Windows.
Placer l'archive de l'image (+ .sha256) et la clé privée dans le dossier parent, puis dans PowerShell :
  powershell -ExecutionPolicy Bypass -File .\Install-DynamicMS.ps1
